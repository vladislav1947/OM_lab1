# ЛР № 1. ЛП-модель распределения ресурсов — вариант 6

«План выработки электроэнергии станциями: минимум затрат» (5 станций, 24 ч).

Студент: Осипов В. А., группа Б24-517. Вариант V = 6, seed данных = 10116
(детерминированная генерация: тот же seed — те же данные).

Солвер: HiGHS через `scipy.optimize.linprog` (open-source, лицензия MIT).

## Установка

Требуется Python 3.12+ и [uv](https://docs.astral.sh/uv/) (или pip).

```bash
uv venv .venv
uv pip install -r requirements.txt
```

Аналогично через pip: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`.

## Запуск (одна команда)

```bash
.venv/bin/python main.py
```

Команда прогоняет весь конвейер: генерацию данных по seed → построение
модели → решение HiGHS → независимую проверку (допуск 1e-7) → сценарные
эксперименты (базовый / дефицитный / стрессовый) → анализ теневых цен →
доп. задание (симплекс vs внутренняя точка) → графики.

Пример команды и типовой вывод:

```bash
.venv/bin/python main.py
# Базовый сценарий: optimal — найдено глобально оптимальное решение ЛП
#   суточные затраты: 11619786.73 руб., время решения: 0.028 с
#   независимая проверка (допуск 1e-7): все ограничения в допуске — True
# Стрессовый сценарий (+20% спроса, −20% мощности): infeasible ...
```

Все артефакты появляются в `output/`: лог солвера `solver_log.txt`,
план `solution.csv`, проверка `verification.csv` (+`verification_summary.txt`),
сценарии `scenarios.csv` и `stress_conflict.csv`, теневые цены `duals.csv`,
`capacity_value.csv`, `shadow_check.csv`, сравнение алгоритмов `algos.csv`,
графики `*.png`. Данные варианта — в `data/`.

## Структура репозитория

```
TASK.md               задание (не изменяется)
PLAN.md               план: формальная модель, шаги, эксперименты
REPORT.md             отчёт (постановка, модель, проверка, сценарии, теневые цены, ответы к защите)
main.py               единый конвейер — вся работа запускается им
requirements.txt      зафиксированные версии библиотек
src/data_gen.py       генерация данных варианта по seed=10116
src/model.py          построение матриц ЛП (баланс, темп, мощность)
src/solve.py          решение scipy.optimize.linprog(method='highs'), лог HiGHS
src/verify.py         независимая проверка чистым NumPy (допуск 1e-7)
src/experiments.py    сценарии, теневые цены, доп. задание
src/plots.py          графики matplotlib (Agg, PNG)
data/                 stations.csv, demand.csv + описание генерации
output/               все результаты прогона (см. выше)
```
